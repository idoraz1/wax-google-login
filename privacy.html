מדיניות פרטיות - WAX

WAX היא מערכת פנימית של משרד נדל"ן, שפועלת על שרת ברשת המקומית של המשרד ומשמשת רק את העובדים שלו.

אילו נתוני Google WAX משתמשת בהם

  • יומן Google (calendar.events): רק כדי ליצור אירועי פולואפ שהמשתמש ביקש ליצור, ולמחוק אותם כשהוא מוחק אותם ב-WAX. WAX לא קוראת את שאר האירועים ביומן.
  • אנשי קשר (contacts.readonly, חשבון המשרד בלבד): קריאת שם ומספר טלפון של אנשי קשר עם תווית "מתווכים", כדי לזהות מודעות של מתווכים.
  • כתובת המייל של החשבון: רק כדי להציג למשתמש לאיזה חשבון הוא מחובר.

שמירה ושיתוף

אסימוני הגישה של Google נשמרים מוצפנים במסד הנתונים של WAX בשרת המשרד בלבד. הנתונים לא נמכרים, לא משותפים עם צד שלישי ולא משמשים לפרסום. אפשר לנתק את החיבור בכל עת מתוך WAX או בהגדרות חשבון Google (https://myaccount.google.com/permissions), ואז האסימון נמחק.

השימוש של WAX במידע שמתקבל מ-Google API עומד ב-Google API Services User Data Policy, כולל דרישות Limited Use.

Privacy policy (English)

WAX is an internal system of a real-estate office, running on a server in the office's local network for its own staff.

Google data used: Google Calendar (calendar.events) only to create the follow-up events a user asks for, and to delete them when the user deletes them in WAX; the office account's contacts (read-only) only to read names and phone numbers of contacts labeled as realtors; the account's email address only to show which account is connected.

Google tokens are stored encrypted in WAX's database on the office server only. Data is not sold, shared with third parties or used for advertising. Users can disconnect at any time in WAX or at https://myaccount.google.com/permissions.

WAX's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.
